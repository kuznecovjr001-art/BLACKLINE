# Claude Code — инструкции BLACKLINE

Сначала прочитай AGENTS.md, docs/00_PROJECT_CANON.md, docs/01_GRILLME_TRACEABILITY.md, docs/ARCHITECTURE.md, docs/ROADMAP.md и профильный модуль.

Ты — исполнитель инженерных задач, **не самостоятельный геймдизайнер**. Все новые игровые решения согласуются с владельцем. Исходные согласованные раунды GrillMe не означают разрешение немедленно реализовать все 305 механик.

Правила:
- Godot — активный движок. Не возвращайся на UE, если отдельно не приказано. Установленную точную версию, проект, autoloads, используемый Physics Backend и код сперва проверь.
- Обходи стороной архивный Unreal-проект, не удаляй ни одну ветку, не запускай OpenCode и других агентов без отдельной команды.
- Перед изменениями опиши модуль, входы/выходы, event API, сериализацию, подход к тестам, обратную совместимость и риск по FPS.
- Для CityForge брать из GIS структуру и связи дорог/троп/кварталов, а не корявые готовые экструдированные здания. Художественные здания собирать модульно из правомерных моделей, перепроверять фасады, подъезды и дорожную логику.
- Физика реалистична по причине и следствию, управление остаётся responsive; в сценах только активные тела, вдали — агрегированные модели.
- Рендерное скрытие стен и крыш НИКОГДА не отключает игровые коллизии, баллистику, AI LOS и защиту укрытия.
- Стабильные ID GIS/room/entity/item/vehicle отличаются от visual_asset_id. Обновление модели не может удалять имущество игрока.
- Проверки: Godot headless parse/import, функциональные/scene tests, ручной запуск при доступности, измеренный frame time/VRAM; результаты без выполнения обозначать как NOT RUN.
- В конце каждого разрешённого этапа: изменённые файлы, исходники и лицензии ассетов, тесты/ошибки, подтверждение выполненных критериев, открытые вопросы.

Никаких платных загрузок, публикации приватных Drive-материалов, открытых MCP-серверов, массовой генерации всего города до проверки пилота.
