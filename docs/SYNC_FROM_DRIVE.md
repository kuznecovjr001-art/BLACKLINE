# Политика синхронизации: Google Drive и GitHub

**Google Drive — приватный архив фактов и исходных ADR. GitHub — публичный, очищенный от секретов рабочий канон и исходники Godot.**

Каждый цикл:
1. Получить через авторизованный Drive connector исходные ADR, даты и статусы APPROVED/DRAFT.
2. Собрать изменения в виде таблицы: source_filename, Q_ID, decision, prior_decision, overrides, status, affected_system.
3. Два независимых GrillMe набора Q1–Q9 не смешивать: GLOBAL-Q и R2B-Q.
4. Обновить соответствующие модульные контракты только из APPROVED. Черновики не выполнять.
5. Провести конфликт-аудит, подписать важные игровые решения владельцем, указать в PR source_ref без раскрытия закрытой ссылки.
6. Записать внутренний подробный sync report в Drive, в GitHub — только публично допустимое изложение.
7. При будущих изменениях библиотеки моделей, графа дорог и зданий сохранять world/entity IDs и state migrations.

Unreal ADR-031/034 про движок — исторические, их технологические инструкции не переопределяют новый пользовательский выбор Godot. Геймдизайн Q001–305 сохраняется. Дубликаты списков не означают новые решения. Глобальный Q306–315 DRAFT.
