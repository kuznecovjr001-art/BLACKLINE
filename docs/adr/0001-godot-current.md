# ADR-GODOT-001: Godot как активный движок BLACKLINE
Дата: 2026-11-09. Статус: APPROVED PRODUCT DIRECTION; локальная установка и проект ещё не проверены этим репозиторием.

Контекст: в архиве есть Godot-прототипы и ранее утверждённый Unreal Engine 5.8. Пользователь сообщил, что уже разрабатывает игру в Godot из-за сложности/длительности работы на Unreal, и попросил организовать новый репозиторий с сохранением механик GrillMe.

Решение: вести текущую разработку под Godot, без автоматической миграции/уничтожения Unreal. Геймдизайн Q001–305 сохраняется; прежний выбор движка UE 5.8 становится историческим решением по runtime и не является текущим указанием.

Последствия: для города нужны собственные проверенные streaming/PCG/LOD решения; лицензированные GLB, визуальная архитектура по GIS-каркасу, профилирование, save migrations и модульная физика. Версия Godot/плагины/рендерер/основной код уточняются при G0.
