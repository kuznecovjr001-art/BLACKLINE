# Проверки и доказательства перед каждым этапом

Артефакт задачи = ID требования, целевой модуль, патч, версия Godot/рендерера/физики, источник/лицензия моделей, логи фактической проверки, измеренное FPS + frame time / RAM / VRAM, скриншоты и список непрошедших тестов.

Набор обязательных сценариев:
1. Проход из улицы в подъезд, лестница и следующий этаж, поворот камеры: roof cutaway влияет только на визуал, пули/AI/укрытия не видят через стены.
2. Прототип здания: точный вход связан с тротуаром, дворы/дороги/сервисные въезды логичны, машина не едет через стены.
3. Автомобиль: отсутствие колеса, утечка радиатора, тип шин, снег/грязь, масса груза дают причинные последствия, без неуправляемого хаоса.
4. Паркур: отдельная команда и взгляд задают направление, целое стекло препятствует пролезанию, руки и вес ограничивают манёвры.
5. Оружие: первый физический контакт с перилом блокирует дугу, разрыв анимации не дублирует оружие/патроны.
6. Зомби: слышат по реальной акустике, используют лестницы, в узких местах создают затор, издалека агрегируются.
7. Время и сохранение: 6x, пустой онлайн-сервер идёт при ограниченной симуляции, offline closed pause; не магически обновляется лут.
8. Группа/база: защищённые объекты, отсрочка 15 минут, нападение 5 минут, общественные маршруты открыты, серверные запреты проверены.
9. Установленный FPS target 60 1080p на отдельно согласованной средней конфигурации; измерения, не обещание.

Если тест не запускался, писать NOT RUN. Нельзя считать документ приёмкой исполнения.
