# Политика 3D-ассетов и художественного направления

Сначала бесплатные и законные модели/текстуры для коммерческой игры. «Бесплатно» не значит CC0. Каждый ассет проходит проверку: автор, канонический URL, конкретная лицензия, разрешённые модификации, credit/attribution, запрет распространения исходного ассета, версия, checksum.

Полезные кандидаты: Poly Haven и ambientCG (обычно CC0 PBR/HDRI), Kenney (часто CC0, но преимущественно для прототипов), Quaternius (проверять условия каждого набора, в том числе QAL), Blendkit, Sketchfab, Fab (для отдельных моделей уточнять права и ограничения). Запрещены кража Google Maps/2GIS кеш-мешей, неразрешённые частные поэтажные планы и автоматическая покупка моделей.

Единая библиотека архитектурных семейств: кирпичные/панельные советские дома, современные ЖК, исторические корпуса, промышленные здания, гаражи/мастерские, общественные здания, частный сектор. Если готовые модели слишком крупные или не совпадают с габаритами, адаптировать в Blender: отдельные секции, корректные входы/крыши/фасады, UV, PBR, LOD, collision proxy. Не смешивать мультяшный low-poly с фотореализмом без целенаправленной стилизации.

3D-пайплайн: source asset (immutable) → лицензия/метаданные → адаптация → GLB/glTF → Godot импорт → визуальная проверка → collision/navmesh/LOD/производительность → релизный manifest. Период катастрофы отражать отдельными decal/props/weather слоями. Не рисовать лут внутри дома случайно, без логики типа помещений.

Рекомендуемые столбцы реестра: asset_id, source_url, author, license, license_url, attribution, redistribution_allowed, modifications, checksum, Godot_version, LOD, textures, collision, review_status.
