# BLACKLINE — этапы и контроль качества

Никаких автоматических переходов между этапами без подтверждения.

| Этап | Продукт | Приёмка |
|---|---|---|
| G0 Аудит | Проверка настоящего Godot-проекта, версии, скриптов, ассетов | отчёт, запуск, git status, baseline |
| G1 Геометрия города | пилот 256–512 м, дороги, пешеходные связи, подъезды | масштаб/перекрёстки/проезды проходимы |
| G2 Архитектура и арт | модульные семейства зданий, LOD/PBR, пропсы | единый визуальный стиль, лицензии |
| G3 Персонаж и камера | WASD, mouse aim, поворот камеры, несколько этажей | без X-ray, коллизии/высота корректны |
| G4 Интерактивный мир | двери, контейнеры, лут, ID, время, погода | события сохраняются при перезагрузке |
| G5 Транспорт | две машины, детали, груз, тяга, ремонт | измеренные эффекты физики и simcade |
| G6 Зомби и орды | зрение/слух, лестницы, локальные заторы | нет телепортации, дальний LOD |
| G7 Базы и ресурсы | питание/вода/оборудование/крафт/claim | реальные зависимости ресурсов, права |
| G8 Персистентность и сеть | офлайн + тестовый сервер 4–8 | нет дублирования лута, clocks корректны |
| G9 Сектора/погода | нагрузочный пилот из нескольких секторов | 1080p60 по выбранному железу, 1440p scalable |
| G10 Альфа | все сценарии + регрессия | фиксация багов, сохранений, замеры |

Цель 32 игрока — **проектная**, не гарантированная. Сначала 4–8. Не строить весь город, пока не протестированы потоковая загрузка, сохранения, AI и collision budget. Нельзя менять один незавершённый масштабный этап на тысячи невалидированных ассетов.
